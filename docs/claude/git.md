# Git

- Un commit par tâche du plan, une fois la tâche vérifiée.
- Messages en français, préfixés : `feat:` (fonctionnalité), `chore:` (outillage, finitions), `style:` (forme du code), `docs:` (notes et documentation).
- Terminer chaque message par la ligne `Co-Authored-By:` fournie par Claude Code.
- `core.autocrlf` est à `false` dans ce dépôt : fins de ligne LF.
- Ne rien pousser et ne rien mettre en ligne (GitHub, Netlify) sans l'accord du porteur du projet.
